# Mouse Temperature and Activity Visualization

A collaborative student project exploring how mouse activity and body temperature vary with time of day and estrus-cycle status.

**Team:** Takafumi Matsui, Devesh Panda, Tim Mao, and Omar Ali.

## Project components

- An interactive D3.js website with activity and temperature visualizations.
- A notebook containing exploratory analysis and supporting figures.
- A view that transitions between daily patterns and a PCA-style scatterplot.

**[View the project website](https://takafumim.github.io/final_proj/)**

## Data and interpretation

This repository contains a mixture of analysis materials and a web visualization. Some values in the website are hard-coded illustrative series, and the PCA-style coordinates in `main.js` are generated for visual demonstration. **The interactive scatterplot should not be interpreted as a PCA fitted to the original experimental observations.**

The original notebook (`final_project.ipynb`) is kept separately for the underlying student analysis.
